## Gotchas
- Daily re-login mandatory; no refresh-token automation post-2026-04-01 (the /validate-refresh-token endpoint still appears in older threads; do not rely on it).
- Static IP must match the egress IP of the Docker host/NAT; Kalpi users each need own IP.
- No multi-id order lookup; poll full /orders sparingly (200/min shared with all calls) or use order WebSocket.
- Reconcile ambiguous place_order by orderTag only after confirming tag is echoed in /orders (UNVERIFIED).
- Span-margin/EDIS still on v2 `api.fyers.in/api/v2` (fyers-skills).
- Docs site myapi.fyers.in/docsv3 must be read in a browser to close the UNVERIFIED items before live use.
