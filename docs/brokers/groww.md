# Groww — groww
Docs (primary): https://groww.in/trade-api/docs/curl (+ /orders, /portfolio, /margin, /instruments, /annexures), https://groww.in/trade-api, https://groww.in/blog/static-ip-api-trading-setup
Base: https://api.groww.in ; headers: `Authorization: Bearer <token>`, `Accept: application/json`, `X-API-VERSION: 1.0`.
Envelope: success `{"status":"SUCCESS","payload":{...}}`; failure `{"status":"FAILURE","error":{"code":"GA###","message":"..."}}` (https://groww.in/trade-api/docs/curl)

1. **Auth flow + token lifetime**: (a) access token generated in Groww web UI, expires daily 6:00 AM; (b) key+secret: `POST /v1/token/api/access`, body `key_type:"approval"`, checksum = SHA256(secret + epoch-timestamp string), timestamp; needs daily approval in Groww UI; (c) TOTP: same endpoint `key_type:"totp"` + 6-digit code. Token endpoint limited to 150 req/24h. Exact body field names UNVERIFIED (not captured). https://groww.in/trade-api/docs/curl
2. **Holdings**: `GET /v1/holdings/user` -> `payload.holdings[]`: `trading_symbol`, `quantity` (net), `average_price`, `pledge_quantity`, `t1_quantity`, `demat_free_quantity`, `isin`. Sellable qty likely = demat_free_quantity (inference; UNVERIFIED). https://groww.in/trade-api/docs/curl/portfolio
3. **Funds**: `GET /v1/margins/detail/user` -> `clear_cash` (also collateral, net margin used, adhoc margin; FnO split). https://groww.in/trade-api/docs/curl/margin
4. **Place order**: `POST /v1/order/create`; required `trading_symbol, quantity(int), validity, exchange, segment, product, order_type, transaction_type`; optional `price, trigger_price, order_reference_id`. Delivery product=`CNC`; order_type LIMIT|MARKET|SL|SL_M; validity DAY (only value documented); exchange NSE|BSE; segment CASH|FNO. Response: `groww_order_id, order_status, order_reference_id, remark`. Cancel: `POST /v1/order/cancel` {groww_order_id, segment}. https://groww.in/trade-api/docs/curl/orders , /annexures
5. **Tag field**: `order_reference_id`, 8-20 alphanumeric chars, max 2 hyphens. Idempotency/duplicate rejection NOT documented (UNVERIFIED) -> treat as lookup key only. https://groww.in/trade-api/docs/curl/orders
6. **Order state**: single `GET /v1/order/status/{groww_order_id}?segment=CASH`; by tag `GET /v1/order/status/reference/{order_reference_id}?segment=CASH` (fields groww_order_id, order_status, filled_quantity, average_fill_price, remark, order_reference_id); book `GET /v1/order/list?segment&page&page_size(max 100)` (+remaining_quantity, deliverable_quantity, created_at...). Also `GET /v1/order/detail/{id}`.
   Status vocab (annexures): NEW, ACKED, TRIGGER_PENDING, APPROVED, REJECTED, FAILED, EXECUTED, DELIVERY_AWAITED, CANCELLED, CANCELLATION_REQUESTED, MODIFICATION_REQUESTED, COMPLETED. Proposed map: NEW/ACKED/APPROVED/TRIGGER_PENDING/*_REQUESTED->OPEN; EXECUTED/DELIVERY_AWAITED/COMPLETED->FILLED (partial = filled_quantity<quantity while open; UNVERIFIED how reported); REJECTED/FAILED->REJECTED; CANCELLED->CANCELLED. Orders doc also shows OPEN, PENDING (undocumented in enum list). https://groww.in/trade-api/docs/curl/annexures
7. **Instruments**: CSV https://growwapi-assets.groww.in/instruments/instrument.csv ; cols exchange, exchange_token, trading_symbol, groww_symbol, instrument_type, segment, lot_size, tick_size, expiry_date, strike_price, buy_allowed, sell_allowed. Orders use exchange + trading_symbol. Refresh cadence UNVERIFIED. https://groww.in/trade-api/docs/curl/instruments
8. **Rate limits** (per s / per min): Orders 10/250; Live data 10/300; Non-trading (status, list, positions, holdings, margin) 20/500; Auth 5/30 (+150/day token). Per-day order cap UNVERIFIED. https://groww.in/trade-api/docs/curl

## Gotchas
- Token dies daily 06:00; approval-flow keys also need daily manual approval -> unattended refresh only plausible via TOTP flow.
- Orders and status endpoints take `segment`; always pass CASH.
- Only DAY validity documented; no documented AMO control on create.
- Order book is paginated (max 100); reconcile by tag via status/reference endpoint after ambiguous failures.
