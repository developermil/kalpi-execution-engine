# Upstox — upstox
Docs: https://upstox.com/developer/api-documentation/ (all links below under this root unless stated). Researched 2026-10-01; fetched via summarising tool, not verbatim.

1. **Auth flow + token lifetime** — OAuth redirect. GET `https://api.upstox.com/v2/login/authorization/dialog?client_id&redirect_uri&response_type=code&state`; then POST `https://api.upstox.com/v2/login/authorization/token` with code, client_id, client_secret, redirect_uri, grant_type=authorization_code (form body presumed; content-type UNVERIFIED). No checksum. Code single-use even on failure. access_token expires 3:30 AM next day regardless of issue time. Redirect URI must match registered exactly; avoid `.php`. Response also has `extended_token` (read-only, long). Errors: UDAPI100069 bad client creds, 100070 bad redirect, 100057 bad code. User supplies: api key, secret, redirect URI, daily login (or semi-automated mobile approval). Src: /authentication/ , /get-token/
2. **Holdings** — GET `/v2/portfolio/long-term-holdings` (base `https://api.upstox.com`; prefix inferred from other v2 paths). Fields: `trading_symbol`, `quantity` (total), `average_price`, `t1_quantity`, `collateral_quantity`, `instrument_token`. Caveat: whether `quantity` includes t1/collateral qty UNVERIFIED (compute sellable defensively). Src: /get-holdings/
3. **Funds** — GET `https://api.upstox.com/v2/user/get-funds-and-margin`, optional `segment=SEC|COM`; field `data.equity.available_margin` (float; since 2025-07-19 equity object holds combined). Service down 00:00-05:30 IST, error UDAPI100072. Src: /get-user-fund-margin/
4. **Place order** — POST `https://api-hft.upstox.com/v3/order/place`. Required: quantity, product (`D` delivery, `I`, `MTF`), validity (`DAY`|`IOC`), price (0 for MARKET), instrument_token, order_type (`MARKET|LIMIT|SL|SL-M`), transaction_type, disclosed_quantity, trigger_price. Optional: tag, is_amo, slice, market_protection. Response `data.order_ids[]` (list; more than one when slice=true). Src: /v3/place-order/ (fetched as http://upstox.com/developer/api-documentation/v3/place-order/)
5. **Tag** — `tag` string, max 40 chars (v3 place). Returned in order book. Order details accepts order_id or tag (UDAPI100059 if neither). Src: /v3/place-order/, /get-order-book/, /get-order-details/
6. **Order state** — single: GET `/v2/order/details?order_id=` (also by tag; exact param UNVERIFIED); book: GET `https://api.upstox.com/v2/order/retrieve-all` (current day only). Status strings (lowercase): open pending/validation pending/put order req received/after market order req received/modify*/trigger pending -> OPEN; open -> OPEN (PARTIAL if filled_quantity>0 and pending_quantity>0, engine-derived); complete -> FILLED; rejected -> REJECTED; cancelled/cancelled after market order -> CANCELLED; cancel pending -> OPEN; not cancelled/not modified -> unchanged. Mapping is mine; the doc has no PARTIAL status. Src: /appendix/order-status/
7. **Instruments** — `instrument_key` = `NSE_EQ|<ISIN>` (e.g. `NSE_EQ|INE839G01010`); holdings return `instrument_token` in same form. Master: `https://assets.upstox.com/market-quote/instruments/exchange/complete.json.gz` (also NSE/BSE/MCX files; JSON recommended, CSV deprecated). Refreshed daily ~6 AM. Src: /instruments/
8. **Rate limits** — Orders: 10/s, 500/min, 2000/30min (regular); 50/s for SEBI-registered algos. Standard APIs 50/s, 500/min, 2000/30min. No per-day figure (30-min window instead). 429 typically with Retry-After (hedged in doc; treat as UNVERIFIED). Excess may cause temporary suspension. Src: /rate-limiting/
9. **Regulatory** — From 2026-04-01: static IP mandatory for order place/modify/cancel/GTT (read APIs unaffected per earlier 2025 post); one active app per user (latest kept); algos >10 orders/s need exchange registration; family IP sharing added May 2026. Primary IP editable once per week. Ref NSE/INVG/67858. `X-Algo-Name` header: UNVERIFIED primary (seen only on third-party blog). Src: https://community.upstox.com/t/important-new-sebi-exchange-mandates-for-api-trading-effective-1st-april-2026/14822 , https://community.upstox.com/t/clarification-on-static-ip-deadline-for-algo-api-trading-october-1-2025/11613
10. **MARKET/MPP** — `market_protection` int on MARKET and SL-M: -1 auto, 0 none, 1-25 percent. Auto/default behaviour when omitted: UNVERIFIED. Prefer LIMIT at marketable price. Src: /v3/place-order/
11. **Cost** — API free ("All trading + data APIs are free of cost"); only brokerage (promo Rs10/order till 2026-09-30, i.e. expired today; current pricing UNVERIFIED). Src: https://upstox.com/trading-api/
12. **Errors** — Codes `UDAPI...`; envelope shape (`status:"error"`, `errors[]`) UNVERIFIED. 429 + `UDAPI10005` too many requests (token endpoint: UDAPI100099). Auth expired: 401 `UDAPI100050` invalid token. 503 maintenance. Reject / insufficient funds codes: UNVERIFIED (per-API 4xx sections; rejection arrives async via status `rejected` + `status_message`). Src: /error-codes/, /get-order-book/
13. **Sandbox** — Yes, orders only (place/multi/modify/cancel, v2 and v3); token valid 30 days from https://account.upstox.com/developer/apps#sandbox; one sandbox app; cannot trade live; holdings/funds/order-book not sandbox-enabled. Sandbox base URL UNVERIFIED. Src: /sandbox/

## Gotchas
- Token dies 3:30 AM daily -> engine must flag "re-login required" before market open; no refresh token.
- Place host (`api-hft`) differs from other APIs (`api`).
- Static IP: orders from non-registered egress IP will be blocked; Docker/cloud egress must be fixed.
- Order book wipes at end of day; reconcile by `tag` same day only.
- Funds API unavailable 00:00-05:30 IST.
